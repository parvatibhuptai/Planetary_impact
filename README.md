# NASA Space Apps: Spatial Blast Radius Simulator

An interactive geospatial simulation tool built for the NASA Space Apps Challenge. This project models hypothetical asteroid impacts and visualizes their spatial blast radius and risk zones on a 3D interactive globe.

## The Core Logic
This tool takes complex geospatial coordinates and impact data and translates them into an accessible, interactive 3D WebGL interface. 
* **Spatial Risk Modeling:** Calculates and maps the theoretical blast radius based on impact parameters.
* **Data Visualization:** Renders high-performance, real-time 3D data points directly onto a virtual Earth model, allowing users to visually interact with spatial data.

## Tech Stack
* **Frontend/Rendering:** JavaScript, Three.js, WebGL
* **Domain:** Geospatial Analytics, Data Visualization, 3D Rendering

## Why this matters
Visualizing planetary data in 2D often loses the scale and reality of the impact. By leveraging Three.js and WebGL, this project demonstrates how to handle spatial intelligence rendering in a 3D environment without overwhelming browser performance.
